免费平台不是越多越好，额度类型配错了，要么很快用光，要么白白过期。

这篇给的是**选型的判断标准**，而不是一份会过期的平台清单——具体每家的额度和核实日期，一律以[资源库](/models/)平台页为准。

## 先搞懂三种免费类型

| 类型 | 特点 | 适合 |
|------|------|------|
| 永久免费模型 | 小参数模型长期免费，**有并发/速率限制** | 学习、调试、轻量日常任务 |
| 注册赠送额度 | 一次性，**有有效期**（30 天、90 天、2 周都有） | 集中体验大参数模型 |
| 每日/周期重置额度 | 按天或按窗口滚动刷新，用不完也**不滚存** | 高频轻任务、长期挂机的应用 |

**最优策略是三者叠加**：日常用永久免费模型，攻坚用注册赠送的体验额度，批量小任务挂周期重置的平台。

**关键洞察**：这三种类型的差异不在"多少"，而在**"什么时候失效"**——永久免费的是限速，赠送的是到期，重置的是当天清零。选型时先问自己「这个应用会连续跑多久」，答案会直接指向某一类。

## 按场景选类型，再挑平台

平台会增减、额度会调整，但**场景与额度类型的对应关系是稳定的**：

**学习和入门** → 找**永久免费的小参数模型**。不限量、限并发，试错成本最低，兼容 OpenAI 格式的更好（同一套代码能迁移）。站内筛选：[国内平台](/models/)里标着永久免费的几家。

**高频轻量任务**（自动打标签、摘要、分类）→ 找**按天重置**的平台。这类任务单次消耗小、次数多，最怕的是"总量用完了"，而每天刷新恰好匹配这个节奏。注意把重置时区弄清楚（见下节）。

**长文本处理**（长文档总结、代码库理解）→ 优先看**上下文长度**，其次才是额度。站内已有上下文达到 100 万级的平台。**提醒**：上下文越长，每轮请求的消耗越大，长文档任务一定要**先小段试**，算准单个文档的成本再批量跑。

**多模态**（图片理解、OCR、视觉任务）→ 选原生支持视觉的模型。注意两点：一是**不是所有平台的免费额度都覆盖多模态**，有的明确标注多模态走收费通道；二是**纯文本模型不要硬塞图片**，多数会直接报错。

**AI 编程**（Cline / Roo Code / Claude Code 等）→ 这是消耗最大、也最需要挑的场景，单独写了一篇：[《用免费 API 白嫖 AI 编程》](/tutorials/ai-coding-tools/)。选型上记住两条：**必须支持工具调用**、**限速要宽松**（Agent 是突发型流量）。

**想一个 Key 调所有模型** → 选合规聚合平台。它们的价值不是便宜，而是**省去逐个平台注册**，适合到处尝鲜、快速比效果。注意区分：合规聚合有主体、有公开定价条款；来路不明的中转站不在此列，判定见[避坑指南](/guide/)。

**重度开源模型玩家** → 选**模型上架快、开源系覆盖全**的平台。这类需求看的是"新模型多久能用到"，而不是额度大小。

> **一个常被忽略的判据**：平台页的**推荐指数**是我们实测后给的评价，包含速度、额度消耗速度、是否有编程套餐等维度。选型时先看它，再看具体额度——**额度和体验是两回事**。

## 同额度不同命：四个必查口径

同样写着"送 X 万 Token"，实际体验可能差很远。这四个口径必须逐个核对：

**① 是否按模型独立发放。** 有的平台免费额度**按模型独立计算、不能跨模型合并**。你会遇到"A 模型还有额度、B 模型已经不能用了"的情况——切模型前先确认。

**② 重置时区。** 有平台按 UTC 零点重置（与北京时间差 8 小时），有平台在凌晨重置，还有按 5 小时/7 天窗口滚动的。**"今天额度没了"往往是时区错觉**。

**③ 用尽后的行为。** 三种可能：**降级**（变慢但仍可用）、**报错**（请求失败）、**服务暂停**（需手动去控制台重新开启）。第三类绝对不能挂主力业务。

**④ 额度是"产品内"还是"可导出"。** 有些平台送的是产品内积分或客户端额度，**不能导出成 API Key 给外部程序用**。如果你要写代码调用，这类额度帮不上忙（本站对这两类做了分区标注，见 `/perks/` 与 `/models/` 的区别）。

## 四个避坑提醒

1. **别把鸡蛋放一个篮子**：免费额度说变就变。应用里留好备选——换 `base_url` 和 `model` 两个字符串的事。具体实现见[《多模型 Fallback 实战》](/tutorials/multi-model-fallback/)。
2. **警惕过期**：注册赠送额度最常见的是 30/90 天。建个表记下每个平台的到期时间，[活动快讯](/deals/)里的截止日期可以直接抄。
3. **网页版免费 ≠ API 免费**：这是新手最容易误判的一条。不少平台网页版聊天永久免费，但 **API 额度完全独立**，Key 不通用、额度不共享、有的还要单独开通模型服务。
4. **只认官方渠道**：任何要你填非官方 `base_url` 的"免费服务"都有数据风险，参见[避坑指南](/guide/)。

## 现在就去领

打开[资源库](/models/)：每个平台都有核实过日期的领取步骤、额度口径与坑点，可以按分类（国内 / 海外 / 聚合）和推荐指数筛。

从**永久免费的小参数模型**开始最顺——先把链路跑通，再谈额度大小。
