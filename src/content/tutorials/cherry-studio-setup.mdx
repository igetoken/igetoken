很多新手卡在同一个地方：拿到了 Key，却不知道往哪填。

这篇用国内免费力度最大的智谱 GLM 系列举例，带你在图形化客户端 Cherry Studio 里完成第一次免费调用——**全程不需要写一行代码**。最后再教你把它扩展成"一个客户端管多家平台"的用法。

> 本文只讲操作路径，不写死具体额度——**额度和有效期会调整，以[智谱平台页](/models/zhipu/)的核实日期为准**。

## 第一步：注册并领取免费额度

1. 打开智谱开放平台（地址见[平台页](/models/zhipu/)的「领取地址」），用手机号注册并登录。
2. 新用户注册后有体验包，可在控制台查看**剩余量**与**有效期**——注意记下到期日，过期作废。
3. 另外注意：**GLM 的 Flash 系列是永久免费模型**，不消耗体验包额度，练手用它就够了。

> ⚠️ **别混淆**：智谱的网页版聊天额度与 API Token 是**两套体系**。网页版能用，不代表 API 有额度。

## 第二步：创建 API Key

1. 登录后在控制台找到「API 密钥」菜单。
2. 点击「创建 API Key」，复制保存好。
3. **Key 只在创建时完整显示一次**，存到密码管理器里，别存进聊天记录和代码仓库。

新创建的 Key 可能需要几秒到几分钟才生效，粘贴后立刻报错先等一会儿再试。

## 第三步：安装并配置 Cherry Studio

1. 到 Cherry Studio 官网下载对应系统的版本并安装。
2. 打开「设置」→「模型服务」，在列表中找到「智谱」。
3. 粘贴刚才的 API Key，确认接口地址为平台页给出的官方地址。
4. 在模型列表中勾选免费模型，保存。

## 第四步：开始对话

回到对话界面，选中刚才的模型，随便问点什么——恭喜，你已经零成本跑通了第一个大模型应用。

## 进阶：一个客户端管多家平台

Cherry Studio 的价值不止于"能用"，而在于**它能把多家平台并排管理**。做法是重复第三步：

1. 在「模型服务」里点「添加」。（除内置厂商外，可添加"OpenAI 兼容"类型。）
2. 从[资源库](/models/)挑下一家平台，**照抄平台页的 `api_base`** 填进接口地址。
3. 粘该平台的 Key，勾选模型，保存。

**为什么值得这么做**（而不只配一家）：

- **额度互补**：一家用完切另一家，不用重新装客户端。
- **效果对比**：同一个问题问两家，比看跑分榜直观得多。
- **规避限流**：某家高峰期限流时，直接切到另一家。

**配置时的三个注意点**：

| 注意点 | 说明 |
|---|---|
| 接口地址别多写路径 | 只填 `.../v1` 这类基地址，**不要**把 `/chat/completions` 也带上 |
| 认证头可能不是 Bearer | 少数平台用 `api-key` 而非 `Authorization`，填错就是 401 |
| 模型 ID 要原样复制 | 大小写和斜杠都敏感，部分模型带组织前缀 |

## 常见问题

- **报 401 / 鉴权失败**：Key 复制不完整、带了空格、或服务商标没选对。排查顺序见[《大模型 API 报错排查手册》](/tutorials/api-error-troubleshooting/)。
- **报 429 / 限流**：免费模型有并发与速率限制，稍等重试即可。
- **报 404**：接口地址写错了（多了或少了 `/v1`），或模型 ID 不存在。
- **以前能用现在不能用了**：先去平台页看口径有没有变，再看[活动快讯](/deals/)有没有相关公告。
