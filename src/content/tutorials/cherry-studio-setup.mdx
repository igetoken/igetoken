很多新手卡在同一个地方：拿到了 Key，却不知道往哪填。这篇教程用国内免费力度最大的智谱 GLM-4-Flash 举例，带你在图形化客户端 Cherry Studio 里完成第一次免费调用——全程不需要写一行代码。

> 原则：本文所有额度数字最后核实于 2026-08-28，以官方页面为准。

## 第一步：注册并领取免费额度

1. 打开 [bigmodel.cn](https://bigmodel.cn)，用手机号注册并登录。
2. 新用户注册即送 **2000 万 Token** 体验包（在控制台可查看剩余量和有效期）。
3. 另外注意：**GLM-4-Flash 是永久免费模型**，不消耗体验包额度，练手用它就够了。

## 第二步：创建 API Key

1. 登录后进入控制台，找到「API 密钥」菜单。
2. 点击「创建 API Key」，复制保存好。
3. Key 只在创建时完整显示一次，请存到安全的地方（别存进聊天记录和代码仓库）。

## 第三步：安装并配置 Cherry Studio

1. 到 Cherry Studio 官网下载对应系统的版本并安装。
2. 打开「设置」→「模型服务」，在列表中找到「智谱」。
3. 粘贴刚才的 API Key，并确认接口地址为智谱官方地址（设置里默认就是）。
4. 在模型列表中勾选 `glm-4-flash`，保存。

## 第四步：开始对话

回到对话界面，选中智谱的 `glm-4-flash` 模型，随便问点什么——恭喜，你已经零成本跑通了第一个大模型应用。

## 常见问题

- **报 401 / 鉴权失败**：Key 复制不完整，或服务商标没选对。
- **报 429 / 限流**：免费模型有并发限制，稍等几秒重试即可。
- **想换平台？** 本站资源库里每个平台页都给了 base_url，Cherry Studio 里重复第三步即可，Key 和接口地址换掉就行。
