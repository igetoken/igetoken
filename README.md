## 收录原则

1. **只收官方正规渠道**——每条信息都能溯源到官方页面
2. **只收可站外 API 调用、或有明确免费额度的资源**；额度类均标注"以官方为准"与最后核实日期
3. **不做**纯倒卖、无价值中转、Token 转售、批量注册、逆向接口相关内容
4. **严格区分两类额度**：能导出 API Key 在站外调用 → 资源库 / 活动快讯；仅产品内 Web / App 使用 → 积分福利专栏
5. **失效条目归档而非删除**——保留详情页与历史记录，永不删除
